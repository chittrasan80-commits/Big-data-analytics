E-Commerce Customer Segmentation using Big Data

A Big Data Analytics project that groups online shoppers by Recency, Frequency and Monetary value (RFM) using K-Means clustering on Apache Spark, so marketing teams can target each group with the right offer.

Big data pipeline

1. IngestOrders CSV or Parquet in HDFS / S3
2. CleanRemove nulls, cancellations, negative quantities
3. FeaturesRecency, Frequency, Monetary per customer
4. ScaleStandardScaler on log-transformed values
5. ClusterSpark MLlib K-Means, k chosen by silhouette
6. ServeSegment table and dashboard

Spark code (PySpark)

from pyspark.sql import SparkSession, functions as F
from pyspark.ml.feature import VectorAssembler, StandardScaler
from pyspark.ml.clustering import KMeans
from pyspark.ml.evaluation import ClusteringEvaluator

spark = SparkSession.builder.appName("CustomerSegmentation").getOrCreate()
df = spark.read.csv("data/online_retail.csv", header=True, inferSchema=True)

df = (df.dropna(subset=["CustomerID"])
        .filter((F.col("Quantity") > 0) & (F.col("UnitPrice") > 0))
        .withColumn("Amount", F.col("Quantity") * F.col("UnitPrice")))

ref = df.agg(F.max("InvoiceDate")).first()[0]
rfm = (df.groupBy("CustomerID").agg(
        F.datediff(F.lit(ref), F.max("InvoiceDate")).alias("Recency"),
        F.countDistinct("InvoiceNo").alias("Frequency"),
        F.sum("Amount").alias("Monetary")))

vec = VectorAssembler(inputCols=["Recency","Frequency","Monetary"], outputCol="raw").transform(rfm)
sc = StandardScaler(inputCol="raw", outputCol="features").fit(vec)
data = sc.transform(vec)

best = None
for k in range(2, 9):
    pred = KMeans(k=k, seed=42).fit(data).transform(data)
    s = ClusteringEvaluator().evaluate(pred)
    print(k, round(s, 3))

model = KMeans(k=5, seed=42).fit(data)
model.transform(data).select("CustomerID","Recency","Frequency","Monetary","prediction") \
     .write.mode("overwrite").csv("output/segments", header=True)

Run on GitHub Pages

  1. Create a new repository on GitHub, for example ecommerce-customer-segmentation.
  2. Upload this index.html file to the root of the repository.
  3. Open Settings → Pages, set Source to Deploy from a branch, choose main and / (root), then Save.
  4. After a minute your site is live at https://YOUR-USERNAME.github.io/ecommerce-customer-segmentation/.

To run it locally, double-click index.html. To run the Spark job, save the code above as segmentation.py and run spark-submit segmentation.py.
